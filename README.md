# Sprints Learning Assistant

An AI-powered assistant that supports students throughout their learning journey.

It brings learning support, progress tracking, programming practice, and career guidance together in one place.

## What it does

- **Understand course materials** — Ask questions and get help with learning topics.
- **Track learning progress** — Check completed modules and learning progress.
- **Practice programming** — Submit Python work and receive feedback.
- **Explore career opportunities** — Get guidance based on learning progress and career interests.

## Getting started

1. Install Python 3.10 or newer.
2. Install dependencies with `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` and add an OpenAI API key if you want AI-powered responses.
4. Run `python -m src.main --chat SPR-1013`.

The project can also run in a basic offline mode without an API key.
